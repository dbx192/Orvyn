**Orvyn, Rust और egui में बना एक उच्च प्रदर्शन वाला डेटाबेस कार्यक्षेत्र है।** SQL लिखें, पंक्तियाँ संपादित करें, स्कीमा डिज़ाइन करें, Redis कुंजियाँ प्रबंधित करें, MongoDB दस्तावेज़ों पर क्वेरी चलाएँ, सर्च इंडेक्स देखें और बड़ी टेबल निर्यात करें — एक ही नेटिव डेस्कटॉप ऐप से।

प्रोडक्शन डेटाबेस से स्थानीय DuckDB विश्लेषण तक, नेटिव प्रोटोकॉल ड्राइवर, HTTP इंटीग्रेशन और ODBC ब्रिज **35 प्रकार के डेटा स्रोतों** को जोड़ते हैं। SQLite अंतर्निहित है और डेस्कटॉप पैकेज में DuckDB 1.5.4 शामिल है।

**नेटिव निष्पादन। वर्चुअलाइज़्ड ग्रिड। स्ट्रीमिंग एक्सपोर्ट। आपकी भाषा में आपका कार्यक्षेत्र।**

## प्रदर्शन को ध्यान में रखकर बना आर्किटेक्चर

| तकनीक | लाभ |
| --- | --- |
| **नेटिव Rust + egui** | कंपाइल किया गया डेस्कटॉप ऐप; Electron या ब्राउज़र रनटाइम की आवश्यकता नहीं। |
| **बैकग्राउंड Tokio रनटाइम** | डेटाबेस कार्य UI थ्रेड से बाहर चलते हैं; ब्लॉकिंग कार्यों के लिए सीमित समवर्ती कार्य वाला वर्कर पूल उपलब्ध है। |
| **वर्चुअलाइज़्ड डेटा ग्रिड** | परिणाम और टेबल दृश्य केवल दिखाई देने वाली पंक्तियाँ बनाते हैं। |
| **सर्वर पर पेजिनेशन, फ़िल्टर और सॉर्टिंग** | सीमित आकार के पेज लोड करें और टेबल फ़िल्टर डेटाबेस पर लागू करें। |
| **पुनः उपयोग योग्य कनेक्शन** | MySQL और PostgreSQL ड्राइवर कनेक्शन पूल का उपयोग करते हैं। |
| **5,000 पंक्तियों के स्ट्रीमिंग बैच** | MySQL/PostgreSQL प्रोटोकॉल ड्राइवर एक बार गिनती करते हैं, फिर डेटा को एक स्कैन में लिखते हैं; एडिटर पेजिनेशन और क्वेरी इतिहास को बायपास करते हैं। |
| **क्रमिक फ़ाइल लेखन** | CSV, JSON, TSV और XLSX क्रमशः लिखे जाते हैं; XLSX वर्कशीट स्थिर मेमोरी मोड का उपयोग करती हैं और पंक्ति सीमा पर नई शीट बनती है। |
| **SQL हाइलाइटिंग में डिबाउंस** | लगातार संपादन को एक साथ संसाधित किया जाता है; बड़े दस्तावेज़ की सीमा पार होने पर हाइलाइटिंग छोड़ दी जाती है। |

टेबल एक्सपोर्ट में प्रगति, रद्द करने का विकल्प और एक साथ कई टेबल एक्सपोर्ट शुरू होने से सुरक्षा मिलती है। अस्थायी फ़ाइलें रद्द करने पर पहले से मौजूद लक्ष्य फ़ाइल को सुरक्षित रखती हैं। अन्य रिलेशनल ड्राइवर पेज के अनुसार एक्सपोर्ट करते हैं। वास्तविक गति सर्वर, क्वेरी प्लान, नेटवर्क, पंक्ति के आकार और फ़ाइल फ़ॉर्मेट पर निर्भर करती है।

## पाँच भाषाएँ, एक ही कार्यक्षेत्र

**English · 简体中文 · हिन्दी · Español · Français**

एक ही ऐप में पाँच इंटरफ़ेस भाषाएँ उपलब्ध हैं। पहली बार शुरू होने पर Orvyn समर्थित सिस्टम भाषा चुनता है। आप इंटरफ़ेस से भाषा बदल सकते हैं; आपकी पसंद अगली बार के लिए सहेजी जाती है। हल्की और गहरी थीम तथा साथ में आने वाले **Inter, JetBrains Mono और Noto Sans CJK** फ़ॉन्ट अंतरराष्ट्रीय टीमों के लिए कार्यक्षेत्र को उपयोगी बनाते हैं।

## समर्थित डेटा स्रोत

| श्रेणी | डेटा स्रोत |
| --- | --- |
| **MySQL प्रोटोकॉल · 8** | MySQL · MariaDB · TiDB · OceanBase · Apache Doris · SelectDB · StarRocks · GoldenDB |
| **PostgreSQL प्रोटोकॉल · 11** | PostgreSQL · TimescaleDB · Redshift · CockroachDB · openGauss · GaussDB · KWDB · KingbaseES · Vastbase · HighGo · UXDB |
| **रिलेशनल और विश्लेषण इंजन · 5** | SQLite · DuckDB · SQL Server · ClickHouse · TDengine (REST) |
| **दस्तावेज़, की-वैल्यू और HTTP SQL · 3** | MongoDB · Redis · Cloudflare D1 |
| **सर्च इंजन · 4** | Elasticsearch · Easysearch · Meilisearch · Manticore Search |
| **विक्रेता ODBC · 4** | Oracle · DM (达梦) · XuguDB (虚谷) · Microsoft Access |

एक प्रोटोकॉल परिवार के स्रोत ड्राइवर साझा करते हैं, जबकि इंजन की विशेषताओं का अलग ध्यान रखा जाता है। ODBC के लिए सिस्टम में संगत विक्रेता ड्राइवर चाहिए। सुविधाएँ इंजन, सर्वर संस्करण और अनुमतियों के अनुसार बदलती हैं।

## रोज़मर्रा के काम के लिए पूरी टूलकिट

- **SQL स्टूडियो:** कई टैब, सिंटैक्स हाइलाइटिंग, फ़ॉर्मेटिंग और उपनाम पहचानने वाला कीवर्ड, टेबल व कॉलम ऑटोकंप्लीशन। वर्तमान स्टेटमेंट, चुना हुआ SQL या पूरा स्क्रिप्ट चलाएँ; अलग परिणाम, समय और प्रभावित पंक्तियाँ देखें। इतिहास, पसंदीदा क्वेरी, ट्रांज़ैक्शन और रद्द करने की सुविधा इंजन के अनुसार उपलब्ध हैं। MySQL/PostgreSQL में सर्वर की क्षमता और अनुमतियों के अनुसार सर्वर पर क्वेरी रद्द की जा सकती है।
- **डेटा देखना और संपादन:** डेटाबेस, स्कीमा, टेबल, व्यू, कॉलम, इंडेक्स, फ़ॉरेन की, ट्रिगर और रूटीन का ऑब्जेक्ट ट्री। पेजिनेशन, फ़िल्टर, सॉर्टिंग और प्राइमरी की आधारित संपादन; बदलाव भेजने से पहले उनका सारांश और पुष्टि।
- **स्कीमा डिज़ाइन:** कॉलम जोड़ना, हटाना, नाम या प्रकार बदलना पहले तैयार करें, फिर लागू करें। प्राइमरी की, इंडेक्स और फ़ॉरेन की के लिए इंजन के अनुसार SQL बनता है। ट्रिगर और रूटीन संपादित करें; PostgreSQL के ओवरलोड सिग्नेचर सुरक्षित रहते हैं।
- **आयात और निर्यात:** CSV, JSON, Excel-संगत TSV और नेटिव XLSX। सटीकता बनाए रखने के लिए बड़े पूर्णांक और दशमलव XLSX में टेक्स्ट के रूप में लिखे जाते हैं। समर्थित इंजनों पर केवल स्कीमा या डेटा सहित SQL एक्सपोर्ट। CSV विज़ार्ड में एन्कोडिंग पहचान, प्रीव्यू, बैच इंसर्ट, प्रगति, रद्द करना और विफल पंक्तियों की रिपोर्ट शामिल हैं।
- **Redis:** कर्सर स्कैन, सपाट या पदानुक्रमित कुंजी दृश्य, String/Hash/List/Set/Sorted Set संपादन, कुंजी बनाना, नाम बदलना, बैच डिलीट, TTL, JSON/रॉ मान और कमांड कंसोल।
- **MongoDB:** फ़िल्टर, प्रोजेक्शन, सॉर्टिंग, पेजिनेशन, एग्रीगेशन और एक दस्तावेज़ को बनाना, बदलना या हटाना।
- **सर्च और D1:** Elasticsearch/Easysearch में mapping-आधारित पूर्णता, रॉ उत्तर, `PIT` / `search_after` डीप पेजिनेशन और वर्तमान पेज का JSON एक्सपोर्ट। Meilisearch/Manticore ब्राउज़िंग तथा Cloudflare D1 पर प्रत्येक स्टेटमेंट के अलग परिणाम के साथ HTTP SQL।

## सुरक्षा और बदलावों पर नियंत्रण

सहेजे गए कनेक्शन क्रेडेंशियल **ChaCha20-Poly1305** से एन्क्रिप्ट होते हैं। कनेक्शन एक्सपोर्ट में डिफ़ॉल्ट रूप से पासवर्ड शामिल नहीं होता। पाँच SSL मोड (`Disable`, `Prefer`, `Require`, `VerifyCa`, `VerifyFull`, कनेक्टर के समर्थन के अनुसार) और रीड-ओनली कनेक्शन मोड उपलब्ध हैं। फ़ाइल लॉक और एटॉमिक सेव कॉन्फ़िगरेशन को सुरक्षित रखते हैं; खाली या अपठनीय मास्टर कुंजी को चुपचाप बदला नहीं जाता।

## डाउनलोड और शुरुआत

पैकेज **[GitHub Releases](https://github.com/dbx192/Orvyn/releases/latest)** से डाउनलोड करें।

| प्लेटफ़ॉर्म | रिलीज़ वर्कफ़्लो का पैकेज |
| --- | --- |
| Windows x86_64 | प्रति-उपयोगकर्ता Inno Setup इंस्टॉलर; एडमिन अधिकार बढ़ाने की आवश्यकता नहीं। |
| Linux x86_64 / amd64 | DuckDB लाइब्रेरी सहित `.deb` पैकेज। |
| macOS Intel x86_64 | DuckDB सहित `.dmg` में `.app`। |
| macOS Apple Silicon aarch64 | DuckDB सहित `.dmg` में `.app`। |

Linux पैकेजिंग और DuckDB तैयारी स्क्रिप्ट ARM64 होस्ट भी संभालती हैं; वर्तमान वर्कफ़्लो Linux x86_64 प्रकाशित करता है।

1. Orvyn इंस्टॉल करें और इच्छित प्रकार का कनेक्शन बनाएँ।
2. कनेक्शन विवरण या स्थानीय डेटाबेस पथ भरें, जाँचें और सहेजें।
3. ऑब्जेक्ट देखें, क्वेरी खोलें या Redis और सर्च के विशेष ब्राउज़र का उपयोग करें।

Windows/Linux शॉर्टकट: `Ctrl+N` नई क्वेरी, `Ctrl+Enter` वर्तमान स्टेटमेंट, `Ctrl+Shift+Enter` चयन, `Ctrl+Shift+F` फ़ॉर्मेट, `Ctrl+L` ऑब्जेक्ट खोज और `Ctrl+T` थीम। macOS पर `Cmd` उपयोग करें।

## स्रोत से बिल्ड करें

आवश्यकताएँ: Rust stable (घोषित न्यूनतम 1.88; CI में 1.96.1), Python 3 और नेटिव बिल्ड टूल। रिलीज़ बिल्ड दोहराने के लिए CI वाला Rust संस्करण उपयोग करें।

- **Windows:** Visual Studio C++ Build Tools और Rust MSVC।
- **Linux:** `build-essential pkg-config unixodbc-dev libgtk-3-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev libwayland-dev`।
- **macOS:** Xcode कमांड लाइन टूल और `brew install unixodbc`।

रिपॉज़िटरी की रूट डायरेक्टरी से:

```sh
python packaging/prepare-duckdb.py
cargo run -p orvyn --release --locked
```

प्रोजेक्ट जाँच:

```sh
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
```

DuckDB 1.5.4 को डिफ़ॉल्ट रूप से `https://gh-proxy.org/` के माध्यम से `packaging/duckdb-download/local/1.5.4/` में डाउनलोड किया जाता है। सीधे GitHub के लिए `ORVYN_GITHUB_PROXY` को खाली स्ट्रिंग रखें, या दूसरा प्रॉक्सी प्रीफ़िक्स दें।

पैकेजिंग: [Windows](packaging/windows/build-installer.ps1) (Inno Setup 6), [Linux](packaging/linux/package.sh), [macOS](packaging/macos/package.sh)। [रिलीज़ वर्कफ़्लो](.github/workflows/ci.yml) `v*` टैग पर चलता है: तीन सिस्टम पर नेटिव परीक्षण और Clippy, PostgreSQL/MySQL/Redis/Elasticsearch इंटीग्रेशन, फिर चार बिल्ड और प्रकाशन।

## कॉन्फ़िगरेशन

| सिस्टम | डायरेक्टरी |
| --- | --- |
| Windows | `%APPDATA%\Orvyn` |
| Linux | `$XDG_CONFIG_HOME/orvyn` या `~/.config/orvyn` |
| macOS | `~/Library/Application Support/Orvyn` |

`ORVYN_CONFIG_DIR` डायरेक्टरी बदलता है। `ORVYN_MASTER_KEY` एन्क्रिप्शन कुंजी देता है; इसके बिना निजी `master.key` बनती है। `RUST_LOG` कॉन्फ़िगरेशन डायरेक्टरी के `orvyn.log` का लॉग स्तर नियंत्रित करता है। **एन्क्रिप्टेड क्रेडेंशियल के साथ कुंजी का बैकअप रखें — उन्हें वापस पाने के लिए वही कुंजी आवश्यक है।**

## संगतता

- ClickHouse, TDengine, Cloudflare D1 और MongoDB क्लाइंट ट्रांज़ैक्शन नियंत्रण नहीं देते।
- रद्द करना कमिट हो चुके काम को वापस नहीं करता। कुछ कनेक्टर केवल क्लाइंट का इंतज़ार रोकते हैं; निदान इसे सर्वर पर पुष्टि किए गए रद्दीकरण से अलग बताते हैं।
- रीड-ओनली मोड क्लाइंट की सुरक्षा है; सर्वर फ़ंक्शन के प्रभाव सीमित करने के लिए डेटाबेस अनुमतियाँ उपयोग करें।
- SSH टनल, स्कीमा/डेटा तुलना, ER डायग्राम, उपयोगकर्ता/अनुमति प्रशासन और स्वचालित अपडेट अभी लागू नहीं हैं।
